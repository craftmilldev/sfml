eyebrow: How to use it
---

SFML ships with an <a href="https://github.com/craftmilldev/sfml/tree/main/example" data-posthog-event="github_repository_visited" data-posthog-link-location="example_implementation">example implementation</a>. Its a CLI that lets you parse, lint and run a factory. Take it for a spin.

Also note, its not optimized for a great developer expereince. Thats not its goal. We encourage you to make your own SFML Runner and share it with the community. Feel free to create a PR with a link to your runner when you have one. We provide conformance tests to make it simple to create conformant SFML Runners if you are interested in doing so. The example project is a great place to see how to use them.

In the mean time, use <a href="https://github.com/craftmilldev/sfml/tree/main/example" data-posthog-event="github_repository_visited" data-posthog-link-location="example_runner">our example runner</a> and get a feel for what working with a factory is like.
