title: Overview

SFML — the Software Factory Markup Language — is a file format for describing a _software factory_:
a durable, resumable, mostly-autonomous pipeline that turns an intent ("implement this issue") into
a reviewed artifact.

The bet SFML makes is that **the factory graph is worth separating from the agent runtime**. A
factory written as a declarative file can be diffed in a pull request, validated before it runs,
dry-run without spending tokens, and moved between runtimes.

## What this specification defines

- **The document model.** A factory declares its `parameters`, an explicit `start` step, and a map
  of `steps`. Steps are `agent`, `human`, `parallel`, or `result`.
- **Routing.** Every edge is a success edge. Connections are an ordered list, first match wins, and
  routing must be total, which is what makes the linter's reachability check sound.
- **The expression language.** A narrow, closed subset of CEL over factory state — enough to route
  on a result, not enough to become a programming language.
- **Concurrency.** One shape: a `parallel` step whose named children run concurrently and join when
  all of them have a result.
- **Failure and resume.** Step failures are exceptions, not routes. Every exception class is
  resumable, and a run survives process death and human-shaped pauses of arbitrary duration.
- **Conformance.** What an implementation must do, must record, and must document about itself.

## What it does not define

SFML is not an agent framework, a scheduler, a workspace format, or an identity system. Tool
definitions, memory, context management, repositories, branches, and who a name resolves to all
belong to the harness. Portability ends at `harness_config`.

## Status

This specification is a **draft** and is not yet stable. The v0.1 scope is frozen in
[the PRD](https://github.com/craftmilldev/sfml/blob/main/PRD.md); this site is where that scope
becomes normative text. Changes are made through
[proposals](https://github.com/craftmilldev/sfml/tree/main/proposals).

The [Schema Reference](/specification/draft/schema) is generated from `schema/draft/schema.ts` and
is the authoritative shape of a factory document.
