# Contributing

Pre-draft, so the most useful contribution is an argument about a decision in [PRD.md](PRD.md) or a
gap in [SPEC.md](SPEC.md). Open an issue.

## Sign your commits

Commits must carry a `Signed-off-by` line, which certifies you have the right to submit the work
under this project's license. See the
[Developer Certificate of Origin](https://developercertificate.org/).

    git commit -s
